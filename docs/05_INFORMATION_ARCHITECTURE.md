# 05. Information Architecture

| 항목 | 내용 |
|---|---|
| 문서 상태 | Draft v0.1 (Step 3) |
| 작성일 | 2026-09-07 |
| 선행 문서 | 02_PRD, 03_MVP_SCOPE, 04_USER_JOURNEYS |
| 관련 문서 | 06_SCREEN_REQUIREMENTS, 07_INTERACTION_SPEC |

이 문서는 사용자 관점의 화면 구조와 이동 경로를 정의한다. URL, 라우팅, 컴포넌트 구조는 다루지 않는다.

---

## 1. 구조 원칙

1. **그래프가 홈이다.** 로그인 후 첫 화면은 항상 나 중심 그래프다. Discover와 Understand는 이 한 화면 안에서 일어난다.
2. **그래프 + 사이드 패널이 기본 틀이다.** Phase 0에서 검증된 구조다. 그래프에서 무엇을 선택하든 패널이 그 맥락(관심사 상세, 사람 프로필, 추천 목록)을 보여준다. 페이지 이동 없이 탐색이 이어진다.
3. **행동과 관리는 리스트다.** 요청함, 연결 목록, 알림함은 그래프가 아닌 리스트 화면이다. 01_PRODUCT_BRIEF 7절의 판단을 따른다.
4. **알림은 화면을 건너뛴다.** 알림에서 온 사용자는 홈이 아니라 행동 화면(해당 요청, 성립 화면)에 바로 도착한다.
5. **모드는 그래프의 상태이지 별도 화면이 아니다.** Similar 모드, Network 모드는 같은 그래프 위에 겹쳐지는 강조 상태다.

---

## 2. 화면 목록

```
[Onboarding]                  가입 흐름. 완료 전에는 아래 어디에도 갈 수 없다
  ├ 초대 / 소개
  ├ 로그인
  ├ 실명 · 표시명
  ├ 관심사 선택
  └ 알림 설정

[Graph] ── 홈                 그래프 + 사이드 패널
  ├ 패널: 기본 (안내 + 추천 진입점)
  ├ 패널: Interest 상세
  ├ 패널: Person Profile
  ├ 패널: Similar People (모드)
  └ 패널: Network 상세 (모드, S2)

[Connections]                 리스트
  ├ 받은 요청
  ├ 보낸 요청
  └ 연결됨

[Networks] (S2)               리스트
  ├ 추천
  ├ 참여 대기
  └ 성립됨

[Notifications]               알림함

[My Profile]                  내 관심사 · 표시명

[Settings]                    알림 채널 · 계정

[Overlay]                     어느 화면 위에서든 열리는 것
  ├ 연결 요청 작성
  ├ 요청 상세 (수락/거절)
  ├ 연결 성립 (Action 안내)
  ├ Network 성립 (Action 안내)
  ├ 후속 확인
  ├ 글 작성 (S1)
  ├ 관심사 제안 (S4)
  └ 신고 (S5)
```

전역 내비게이션은 다섯 개다: **그래프 · 연결 · 네트워크(S2) · 알림 · 내 프로필**. 설정은 내 프로필 아래에 둔다.

## 3. 화면별 정의

### 3.1 Onboarding

| 항목 | 내용 |
|---|---|
| 목적 | 최소 입력으로 그래프에 도달시키고, 무엇이 언제 공개되는지 이해시킨다 |
| 사용자 행동 | 로그인, 실명 입력, 표시명 선택, 관심사 선택, 알림 허용 |
| 핵심 정보 | 서비스 세 문장 설명, 공개 범위 안내(연결 전 표시명/관심사, 연결 후 실명), 관심사 목록과 선택 개수, 알림 채널 |
| 이어지는 경로 | 완료 → Graph(홈). 미완료 이탈 → 다음 진입 시 중단 지점에서 재개 |
| 하위 단계 | 초대/소개 → 로그인 → 실명·표시명 → 관심사 선택 → 알림 설정 |

관심사 선택은 온보딩 단계이자 My Profile에서 재사용되는 화면이다. 같은 화면이어야 "수정하면 그래프가 바뀐다"는 감각이 유지된다.

### 3.2 Graph (홈)

| 항목 | 내용 |
|---|---|
| 목적 | 나를 중심으로 관심사와 사람의 관계를 탐색하고, 추천 이유를 시각적으로 이해한다 |
| 사용자 행동 | 이동/확대, 관심사 클릭, 사람 클릭, 배경 클릭(선택 해제), Similar 모드 켜기/끄기, Network 모드 켜기/끄기 |
| 핵심 정보 | 나(강조), 내 관심사, 관련도 높은 사람, 그들의 관심사. 표시 상한과 "N명 더" 안내 |
| 이어지는 경로 | 관심사 → 패널 Interest 상세 / 사람 → 패널 Person Profile / 상단 버튼 → Similar 모드, Network 모드 / 전역 내비 → Connections, Notifications, My Profile |
| 기본 상태 | 아무것도 선택되지 않음. 패널은 "기본" 상태 |

그래프의 범위와 상한은 06_SCREEN_REQUIREMENTS §1.1에 정의되어 있다.

### 3.3 패널: 기본

| 항목 | 내용 |
|---|---|
| 목적 | 첫 진입자에게 무엇을 할지 알려주고, 추천 진입점을 준다 |
| 핵심 정보 | 범례(나/사람/관심사), "사람이나 관심사를 눌러보세요", "나와 비슷한 사람 보기" 버튼, 추천 네트워크 요약(S2), 새 알림 요약 |
| 이어지는 경로 | Similar 모드, Network 모드, Notifications |

### 3.4 패널: Interest 상세

| 항목 | 내용 |
|---|---|
| 목적 | 한 관심사를 중심으로 사람을 발견한다 (J1) |
| 사용자 행동 | 사람 목록 훑기, 사람 클릭, 글 읽기, 글 쓰기(S1), 목록 더 보기 |
| 핵심 정보 | 관심사 이름과 Category, 이 관심사를 가진 사람 수, 내가 가진 관심사인지, 사람 목록(표시명, 공통 개수, 연결 상태; 공통 많은 순), 최근 글(S1) |
| 이어지는 경로 | 사람 → Person Profile / 글 작성자 → Person Profile / 글 작성 → Overlay / 닫기 → 기본 |

### 3.5 패널: Person Profile

| 항목 | 내용 |
|---|---|
| 목적 | 이 사람이 누구이고 왜 나와 관련 있는지 이해하고, 요청 여부를 결정한다 (J2) |
| 사용자 행동 | 관심사 클릭(그 관심사로 이동), 연결 요청, 요청 취소(S6), 수락/거절(요청 받은 상태), 신고(S5) |
| 핵심 정보 | 표시명과 실명 여부 표시, 관심사 전체(공통 구분), 공통 개수, 연결 상태와 그 상태에서 가능한 행동만, 최근 글(S1). 연결됨 상태면 실명과 성립 화면 진입점 |
| 이어지는 경로 | 연결 요청 → Overlay 요청 작성 / 관심사 → Interest 상세 / 연결됨 → 연결 성립 화면 / 닫기 → 기본 |
| 나 자신 | 연결 행동 없음. "관심사 수정" 진입점만 |

### 3.6 패널: Similar People (모드)

| 항목 | 내용 |
|---|---|
| 목적 | 나와 비슷한 사람을 이유와 함께 본다 (J4) |
| 사용자 행동 | 목록 훑기, 사람 클릭(강조 + 카드), 연결 요청, 모드 끄기 |
| 핵심 정보 | 추천 인원 수, 기준 설명("공통 관심사 N개 이상"), "선은 관심사가 겹친다는 뜻입니다" 안내, 목록(표시명, 공통 개수, 공통 관심사 이름, 연결 상태), 선택한 사람 카드 |
| 이어지는 경로 | 사람 → 카드(모드 유지) → 연결 요청 Overlay / 모드 끄기 → 기본 |
| 그래프 상태 | 나와 추천된 사람 사이 Similarity Edge, 나머지 흐림 |

### 3.7 패널: Network 상세 (모드, S2)

| 항목 | 내용 |
|---|---|
| 목적 | 추천된 그룹의 구성과 이유를 보고 참여를 결정한다 (J5) |
| 사용자 행동 | 멤버 클릭, 연결하기(참여), 거절, 모드 끄기 |
| 핵심 정보 | 멤버 수와 표시명, 전원 공통 관심사, "왜 묶였는지" 한 줄, 현재 참여 인원 / 성립 기준, 만료까지 남은 기간, "먼저 참여하면 시작자가 됩니다" |
| 이어지는 경로 | 멤버 → Person Profile(모드 유지) / 참여 → 상태 갱신 / 성립 → Network 성립 Overlay / 모드 끄기 → 기본 |
| 그래프 상태 | 허브 노드 + 멤버 선. 개별 관심사 노드는 흐림 (06 §1.2) |

### 3.8 Connections

| 항목 | 내용 |
|---|---|
| 목적 | 요청과 연결을 처리하고 관리한다 (J2, J3) |
| 탭 | 받은 요청 / 보낸 요청 / 연결됨 |
| 사용자 행동 | 받은 요청: 열기, 수락, 거절, 신고. 보낸 요청: 상태 확인, 취소(S6). 연결됨: 성립 화면 열기, "메신저에서 메시지를 보냈어요" 표시 |
| 핵심 정보 | 받은 요청: 표시명, 공통 개수, 메시지 첫 줄, 남은 기간. 보낸 요청: 표시명, 상태(대기/응답 없음/만료). 연결됨: 실명, 공통 관심사, 시작자 표시, 대화 시작 여부 |
| 이어지는 경로 | 항목 → 요청 상세 Overlay 또는 연결 성립 Overlay / 사람 → Graph의 Person Profile |
| 빈 상태 | 받은 요청 없음: "아직 받은 요청이 없습니다. 관심사를 늘리면 발견될 가능성이 높아집니다." 연결 없음: "나와 비슷한 사람 보기" 진입점 |

### 3.9 Networks (S2)

| 항목 | 내용 |
|---|---|
| 목적 | 추천 네트워크와 참여 상태를 관리한다 |
| 탭 | 추천 / 참여 대기 / 성립됨 |
| 사용자 행동 | 추천 카드 열기(→ Graph Network 모드), 참여, 거절, 성립 화면 열기, "초대했어요" 표시 |
| 핵심 정보 | 카드별 멤버, 공통 관심사, 참여 현황, 남은 기간. 성립됨: 멤버 실명, 시작자, 초대 여부 |
| 이어지는 경로 | 카드 → Graph Network 모드 / 성립됨 → Network 성립 Overlay |

### 3.10 Notifications

| 항목 | 내용 |
|---|---|
| 목적 | 나에게 온 것을 모아 보고 바로 처리한다 (J6) |
| 사용자 행동 | 항목 클릭 → 행동 화면 직행, 읽음 처리 |
| 핵심 정보 | 종류(요청/수락/성립/재안내/후속 확인/묶음), 상대 표시명, 판단 근거 요약, 시간, 처리 여부 |
| 이어지는 경로 | 요청 → 요청 상세 / 수락·성립 → 성립 화면 / 묶음 → Similar 모드 또는 Interest 상세 |

### 3.11 My Profile

| 항목 | 내용 |
|---|---|
| 목적 | 내가 어떻게 보이는지 확인하고 관심사를 수정한다 |
| 사용자 행동 | 관심사 수정(온보딩과 같은 화면), 표시명 변경(닉네임 ↔ 실명), 실명 수정, 내가 쓴 글 관리(S1) |
| 핵심 정보 | 남에게 보이는 그대로의 미리보기(연결 전 모습 / 연결 후 모습), 관심사 개수와 상한 |
| 이어지는 경로 | 관심사 수정 → 저장 → Graph(변경 반영) / Settings |

### 3.12 Settings

| 항목 | 내용 |
|---|---|
| 목적 | 알림과 계정을 관리한다 |
| 사용자 행동 | 채널별 알림 켜기/끄기(받은 요청은 최소 한 채널 유지), 브라우저 알림 허용, 외부 채널 등록(S3a), 계정 연결 해제, 탈퇴 |
| 핵심 정보 | 채널별 상태 |

### 3.13 Overlay

| Overlay | 목적 | 핵심 정보 | 닫힌 뒤 |
|---|---|---|---|
| 연결 요청 작성 | 메시지와 함께 요청 | 상대 표시명, 공통 관심사, 메시지 입력, 실명 공개 안내, 남은 횟수 | 원래 패널, 상태 "요청 보냄" |
| 요청 상세 | 수락/거절 판단 | 보낸 사람 프로필 요약, 공통 관심사, 메시지 전문, 수락 시 실명 공개 안내(닉네임 사용자), 수락/거절/신고 | 수락 → 연결 성립 Overlay. 거절 → Connections |
| 연결 성립 | Action 안내 | 상대 실명, 공통 관심사, 요청 메시지, "누가 누구에게" 지시, 메신저 링크(가능 시), "메신저에서 메시지를 보냈어요" / "연락을 받았어요" | Connections 연결됨 |
| Network 성립 | Action 안내 | 멤버 실명 목록(복사), 공통 관심사, 시작자 지시, "초대했어요" | Networks 성립됨 |
| 후속 확인 | H5 신호 수집 | "대화를 시작하셨나요?" 예/아니오, 아니오 시 이유 하나 | 원래 화면 |
| 글 작성 (S1) | 관심사에 글 남기기 | 관심사 이름, 입력, 길이 상한 | Interest 상세 |
| 관심사 제안 (S4) | 없는 관심사 제안 | 이름 입력, 비슷한 기존 관심사 제시 | 원래 화면 |
| 신고 (S5) | 사람/글 신고 | 사유 선택, 설명 | 원래 화면 |

## 4. 이동 경로 지도

```
                     ┌──────────────────────────────────────┐
                     │            전역 내비게이션             │
                     │ 그래프 · 연결 · 네트워크 · 알림 · 프로필 │
                     └──────────────────────────────────────┘
                                       │
   Onboarding ──완료──▶ Graph(홈) ◀────┼────▶ Connections ──▶ 요청 상세 ─수락─▶ 연결 성립
                         │             │            │
        ┌────────────────┼──────┐      │            └──▶ 연결됨 ──▶ 연결 성립
        ▼                ▼      ▼      │
   Interest 상세   Person Profile  Similar 모드     Notifications ──직행──▶ 요청 상세 / 연결 성립 / Network 성립
        │                │      │      │
        └───▶ Person ◀───┘      │      │
              Profile ──요청──▶ 요청 작성 Overlay
                                       │
                          Network 모드 ◀─┼──▶ Networks ──▶ Network 성립
                                       │
                                  My Profile ──▶ 관심사 수정(=온보딩 화면) ──저장──▶ Graph
                                       │
                                   Settings
```

읽는 법: Graph 안의 패널 전환은 페이지 이동이 아니다. Connections, Networks, Notifications, My Profile은 페이지 이동이며, 그 안에서 사람을 누르면 Graph로 돌아와 Person Profile이 열린다.

## 5. 화면 수와 MVP 매핑

| 화면 | MVP 등급 | 비고 |
|---|---|---|
| Onboarding 5단계 | Must | 알림 설정 단계는 브라우저 허용 권유 포함 |
| Graph + 패널 기본/Interest/Person/Similar | Must | |
| 패널 Network | Should (S2) | 게이트 통과 시 |
| Connections 3탭 | Must | |
| Networks 3탭 | Should (S2) | |
| Notifications | Must | |
| My Profile | Must | 관심사 수정, 표시명 변경 |
