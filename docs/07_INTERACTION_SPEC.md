# 07. Interaction Specification

| 항목 | 내용 |
|---|---|
| 문서 상태 | Draft v0.1 (Step 4) |
| 작성일 | 2026-09-07 |
| 선행 문서 | 06_SCREEN_REQUIREMENTS |

각 인터랙션에 대해 전제, 사용자 행동, 즉시 반응, 결과 상태, 패널 변화, 예외를 정의한다. 구현 기술은 다루지 않는다. "hover"는 포인터 장치가 있는 환경의 동작이며, 없는 환경에서는 hover에 해당하는 정보가 click 결과에 포함되어야 한다.

---

## 1. 공통 원칙

| 원칙 | 내용 |
|---|---|
| 한 번에 하나만 선택 | 그래프에서 선택된 노드는 항상 0개 또는 1개다. 새 선택은 이전 선택을 대체한다 |
| 모드는 선택과 독립 | Similar/Network 모드는 켜고 끄는 상태다. 모드 안에서 노드를 선택해도 모드는 유지된다 |
| 배경 클릭은 한 단계만 되돌린다 | 선택이 있으면 선택 해제. 선택이 없고 모드가 켜져 있으면 모드 해제. 둘 다 없으면 아무 일도 없다 |
| 패널은 그래프를 따라간다 | 그래프에서 무엇을 하든 패널이 그 맥락을 보여준다. 패널에서 사람이나 관심사를 누르면 그래프도 따라 강조된다 |
| 카메라는 사용자를 놀라게 하지 않는다 | 노드 선택만으로 화면이 크게 이동하지 않는다. 모드 전환과 앵커 변경 때만 자동으로 맞춘다 |
| 되돌리기 가능 | 요청 취소(S6), 모드 끄기, 앵커 복귀, 선택 해제가 항상 한 번의 행동으로 가능하다 |
| 되돌릴 수 없는 것은 확인한다 | 수락(실명 공개), 탈퇴는 한 번 더 묻는다. 거절과 요청 보내기는 묻지 않는다 |
| Esc | 열린 Overlay 닫기 → 선택 해제 → 모드 해제 순서 |

## 2. 그래프 인터랙션

### 2.1 Person Hover

| 항목 | 내용 |
|---|---|
| 전제 | 그래프에 사람 노드가 보인다 |
| 행동 | 사람 노드 위에 포인터를 올린다 |
| 즉시 반응 | 노드가 살짝 커지고 이름이 보인다(축소 상태에서 숨겨졌더라도). 툴팁: 표시명(실명 표시), 나와 공통 관심사 N개, 연결 상태 |
| 결과 상태 | 변화 없음. 포인터가 떠나면 원래대로 |
| 예외 | 흐림 상태(다른 것이 선택됨)여도 hover 반응은 있어야 한다. 흐려진 사람도 볼 수 있어야 탐색이 끊기지 않는다 |

### 2.2 Person Click

| 항목 | 내용 |
|---|---|
| 전제 | 사람 노드가 보인다 |
| 행동 | 사람 노드를 클릭 |
| 즉시 반응 | 그 사람이 선택 강조. 그 사람의 관심사(그래프에 없던 것은 임시 추가)가 강조되고 그 사람–관심사 선이 강조. 나와 공통인 관심사는 더 강하게. 나머지 흐림 |
| 결과 상태 | Person 선택 상태. 모드가 켜져 있었다면 유지 |
| 패널 | Person Profile로 전환 |
| 카메라 | 이동하지 않는다. 임시 추가된 관심사가 화면 밖이면 그쪽으로 살짝만 |
| 예외 | 나 자신 클릭: 내 관심사 강조 + 패널은 내 프로필(관심사 수정 진입점). Similar 모드에서 추천 목록의 사람 클릭: 2.9 참조. 같은 사람 재클릭: 선택 유지(해제하지 않음). 해제는 배경 클릭 |

### 2.3 Interest Hover

| 항목 | 내용 |
|---|---|
| 행동 | 관심사 노드 위에 포인터 |
| 즉시 반응 | 툴팁: 관심사 이름, Category, 가진 사람 수, 내 관심사 여부. 그 관심사에 연결된 사람 노드가 살짝 강조 |
| 결과 상태 | 변화 없음 |

### 2.4 Interest Click

| 항목 | 내용 |
|---|---|
| 행동 | 관심사 노드를 클릭 |
| 즉시 반응 | 그 관심사 선택 강조. 그 관심사를 가진 사람(그래프에 있는)과 선이 강조. 나머지 흐림 |
| 결과 상태 | Interest 선택 상태. 앵커는 바뀌지 않는다 |
| 패널 | Interest 상세로 전환. "이 관심사를 중심으로 보기" 버튼 포함 |
| 예외 | 인접 관심사(계층 3) 클릭: 같은 동작. 단, 그래프에 있는 사람만 강조되므로 패널에 "그래프 밖에 N명 더 있음 · 중심으로 보기" 안내. 내 관심사 클릭 시 패널에 "내 관심사" 표시 |

### 2.5 "이 관심사를 중심으로 보기" (앵커 변경)

| 항목 | 내용 |
|---|---|
| 전제 | Interest 상세 패널이 열려 있다 |
| 행동 | 버튼 클릭 |
| 즉시 반응 | 그래프가 06 §1.1 "앵커 = 관심사" 구성으로 바뀐다. 전환 애니메이션으로 "재구성됐다"가 느껴져야 한다. 카메라 자동 맞춤 |
| 결과 상태 | 앵커 = 관심사. 선택 = 그 관심사. 상단에 "#백엔드 중심" 표시와 "내 그래프로 돌아가기" |
| 패널 | Interest 상세 유지 |
| 예외 | 모드가 켜져 있었다면 끈다(모드는 나 중심 그래프의 개념이다). Similar 모드에서 앵커 변경 시 "비슷한 사람 보기는 내 그래프에서 볼 수 있습니다" 안내 |

### 2.6 "내 그래프로 돌아가기"

| 항목 | 내용 |
|---|---|
| 행동 | 버튼 클릭 |
| 즉시 반응 | 나 중심 구성으로 복귀. 카메라 자동 맞춤 |
| 결과 상태 | 앵커 = 나. 선택 없음. 패널 = 기본 |

### 2.7 Graph Background Click

| 항목 | 내용 |
|---|---|
| 행동 | 노드/선이 아닌 곳을 클릭 |
| 즉시 반응 | §1 원칙대로 한 단계 되돌림 |
| 결과 상태 | 선택 있음 → 선택 해제(모드 유지, 패널은 모드 패널 또는 기본). 선택 없음 + 모드 켜짐 → 모드 해제(패널 기본). 둘 다 없음 → 변화 없음 |
| 예외 | 드래그(이동)의 끝은 클릭으로 취급하지 않는다 |

### 2.8 Similar People Mode On

| 항목 | 내용 |
|---|---|
| 전제 | 앵커 = 나 |
| 행동 | "나와 비슷한 사람 보기" 토글 켬 (상단 또는 기본 패널 버튼) |
| 즉시 반응 | 나와 상위 `[P-15]`명 사이에 Similarity Edge가 그려지고 숫자 배지. 그래프에 없던 사람은 임시 추가. 나머지 흐림. 카메라는 나와 선이 그어진 사람들이 모두 보이도록 맞춤 |
| 결과 상태 | Similar 모드. 선택 없음 |
| 패널 | Similar 목록 |
| 예외 | 추천 0명: 모드는 켜지되 선 없음, 패널에 빈 상태. 앵커가 관심사면 먼저 나 중심으로 복귀 후 켠다 |

### 2.9 Similar 모드에서 사람 선택

| 항목 | 내용 |
|---|---|
| 행동 | 그래프의 사람 노드 클릭 / 패널 목록 항목 클릭 / Similarity Edge 클릭 |
| 즉시 반응 | 그 사람의 Edge가 굵어지고, 그 사람과 나의 공통 관심사 노드와 양쪽 선이 강조. 다른 Edge는 유지되되 약해짐 |
| 결과 상태 | Similar 모드 + Person 선택 |
| 패널 | Similar 목록 상단에 그 사람 카드(표시명, 공통 관심사, 연결 요청). 목록은 아래에 유지 |
| 예외 | 목록에서 그래프 밖 사람(11위 이하) 클릭: 그 사람이 임시로 그래프에 나타나고 Edge가 그어진다. 추천 아닌 사람(흐려진 사람) 클릭: 모드를 유지한 채 Person Profile로 전환하되 "이 사람은 공통 관심사가 `[P-03]`개 미만입니다" 표시 |

### 2.10 Similar People Mode Off

| 항목 | 내용 |
|---|---|
| 행동 | 토글 끔 / 패널 "모드 끄기" / 배경 클릭(선택 없을 때) / Esc |
| 즉시 반응 | Edge와 임시 추가된 사람이 사라지고 기본 강조로 복귀. 카메라는 기본 구성으로 맞춤 |
| 결과 상태 | 기본 상태. 패널 기본 |
| 예외 | 요청 작성 Overlay가 열려 있으면 모드를 끌 수 없다(Overlay 먼저 닫기) |

### 2.11 Similarity Edge Hover

| 항목 | 내용 |
|---|---|
| 행동 | 선 또는 숫자 배지 위에 포인터 |
| 즉시 반응 | 툴팁: "공통 관심사 N개" + 이름 전부. 그 선이 굵어지고 양 끝 사람이 강조 |
| 결과 상태 | 변화 없음 |
| 예외 | 선이 겹쳐 가리키기 어려우면 숫자 배지가 hover 대상이 되어야 한다. 배지는 선보다 크다 |

### 2.12 Similarity Edge Click

- 2.9와 동일. 선의 반대편 사람이 선택된다.

### 2.13 Network Recommendation Click (S2)

| 항목 | 내용 |
|---|---|
| 전제 | 게이트 통과, 나에게 추천이 있다 |
| 행동 | 기본 패널의 네트워크 요약 / Networks 화면의 카드 / 상단 "추천 네트워크" 토글 |
| 즉시 반응 | Network 모드: 허브 노드가 나타나고 멤버(나 포함)가 허브에 선으로 연결. 멤버 중 그래프에 없던 사람은 임시 추가. 나머지 흐림. 카메라는 허브와 멤버가 보이도록 맞춤 |
| 결과 상태 | Network 모드 + 특정 네트워크 선택 |
| 패널 | Network 상세 |
| 예외 | 추천이 여러 개면 패널 상단에서 전환. 전환 시 허브만 교체되고 카메라 재맞춤. Similar 모드가 켜져 있었다면 끈다(두 모드는 동시에 켜지지 않는다) |

### 2.14 Network 허브 Hover / 멤버 Click (S2)

| 항목 | 내용 |
|---|---|
| 허브 hover | 전원 공통 관심사 노드가 잠시 강조되어 교집합임을 보여준다. 툴팁: "이 N명이 모두 가진 관심사 K개" |
| 멤버 click | Person Focus로 전환하되 모드 유지. 패널은 Person Profile, 상단에 "네트워크로 돌아가기". 허브와 허브 선은 남아 있다 |
| 모드 끄기 | 허브, 허브 선, 임시 추가 사람이 사라지고 기본 복귀 |

### 2.15 확대 / 축소 / 이동

| 항목 | 내용 |
|---|---|
| 행동 | 휠, 핀치, 드래그, 구석 버튼(+, −, 맞춤) |
| 반응 | 그래프만 움직인다. 패널은 고정. 레이블은 확대 수준에 따라 사람 이름을 숨길 수 있으나 강조된 사람 이름은 항상 보인다 |
| 예외 | 노드 드래그(위치 이동)는 허용하되, 놓으면 힘에 의해 다시 자리를 잡는다. 사용자가 배치를 "저장"하는 기능은 없다 |

## 3. 연결 인터랙션

### 3.1 Connection Request (요청 보내기)

| 항목 | 내용 |
|---|---|
| 전제 | 상대와 관계 없음, 남은 횟수 > 0, 나 자신 아님 |
| 진입 | Person Profile / Similar 카드 / Interest 상세 사람 목록의 "연결 요청" |
| 행동 1 | 버튼 클릭 → 요청 작성 Overlay |
| 행동 2 | 메시지 입력(필수) → "보내기" |
| 즉시 반응 | Overlay 닫힘. "○○님에게 요청을 보냈습니다" 토스트. 프로필/목록/노드의 상태가 "요청 보냄"으로. 남은 횟수 감소 |
| 결과 상태 | 요청 대기. 보낸 요청 목록에 추가 |
| 상대 측 | 즉시 알림(이메일 / 브라우저 / 앱 내). 알림 내용: 표시명, 공통 개수와 이름, 메시지 첫 줄 |
| 예외 | 빈 메시지: 보내기 비활성. 상한 초과: Overlay 대신 "오늘 보낼 수 있는 요청을 모두 사용했습니다". 보내는 사이 상대가 나에게 먼저 요청함: "이 사람이 먼저 요청했습니다"로 전환, 수락 유도. 확인 대화상자 없음(취소 가능하므로) |

### 3.2 Request Cancel (S6)

| 항목 | 내용 |
|---|---|
| 전제 | 요청 대기 중, 상대가 아직 처리하지 않음 |
| 행동 | 보낸 요청 목록 / Person Profile의 "취소" |
| 즉시 반응 | 상태 "관계 없음"으로 복귀. 상대의 받은 요청에서 조용히 사라짐(알림 없음). 이미 보낸 외부 알림은 회수하지 않는다 |
| 예외 | 취소한 요청은 횟수를 돌려주지 않는다(취소로 상한을 우회하지 못하게). 취소 후 재요청은 즉시 가능하되 하루 1회 |

### 3.3 Connection Accept

| 항목 | 내용 |
|---|---|
| 전제 | 받은 요청이 대기 중 |
| 진입 | 알림 → 요청 상세 Overlay / Connections 받은 요청 / Person Profile |
| 행동 | "수락" 클릭 |
| 확인 | 닉네임 사용자: "수락하면 내 실명(○○○)이 상대에게 공개됩니다. 수락할까요?" 실명 사용자: 확인 없이 진행 |
| 즉시 반응 | 요청 상세가 연결 성립 Overlay로 바뀐다(페이지 이동 없음). 상대 실명, 공통 관심사, 메시지, Action 안내("○○님이 먼저 연락할 예정입니다") |
| 결과 상태 | 양쪽 "연결됨". 받은 요청 목록에서 제거, 연결됨 목록에 추가. 그래프 노드에 연결 표시. 추천 목록에서 "연결됨"으로 구분 |
| 상대 측 | 즉시 알림 "○○님이 수락했습니다" → 연결 성립 Overlay 직행. 시작자 Action 안내 |
| 예외 | 요청이 이미 만료/취소됨: "이미 처리된 요청입니다". 동시에 서로 요청한 상태: 한쪽이 수락하면 양쪽 요청이 모두 정리되고 시작자는 먼저 보낸 사람 |

### 3.4 Connection Reject

| 항목 | 내용 |
|---|---|
| 행동 | "거절" 클릭 |
| 확인 | 없음. 대신 버튼 옆에 "상대에게 알려지지 않습니다" 상시 표시 |
| 즉시 반응 | 요청이 목록에서 사라짐. Overlay 닫힘. 토스트 "요청을 거절했습니다. 상대에게는 알려지지 않습니다" |
| 결과 상태 | 관계 "응답 없음"(보낸 쪽 관점). 같은 사람의 재요청은 `[P-07]` 동안 불가. 추천 목록에서 그 사람은 흐려지거나 숨김(09 정책) |
| 상대 측 | 알림 없음. 보낸 요청 목록에서 "응답 없음"으로 바뀌는 시점은 즉시가 아니라 거절 후 **최대 하루** `[P-08a]`. 즉시 표시로 거절을 확신하게 하지 않되, 오래 기다리게 하지도 않는다 |
| 예외 | 거절 직후 "실수였어요" 되돌리기: 토스트에 5초간 "되돌리기". 이후 불가 |

### 3.5 Report (S5)

| 항목 | 내용 |

| 진입 | Person Profile 더보기 / 요청 상세 / 글 |
| 행동 | 사유 선택 + 설명(선택) → 제출 |
| 즉시 반응 | "운영자가 확인합니다" 토스트. 화면 변화 없음 |
| 결과 상태 | 신고 접수. 신고자에게 결과 통보 없음. 차단 기능은 없으므로 상대는 계속 보인다 |

## Step 4 결정 사항 / 미결정 사항 (Interaction)

### 결정됨

- 선택은 항상 하나. 배경 클릭은 한 단계만 되돌린다(선택 → 모드).
- Similar와 Network 모드는 동시에 켜지지 않는다. 앵커 변경 시 모드는 꺼진다.
- 노드 선택으로는 카메라가 움직이지 않는다. 모드 전환과 앵커 변경 때만 자동 맞춤.
- 수락(닉네임 사용자), 첫 Network 참여자는 확인을 거친다. 요청 보내기와 거절은 확인 없음(대신 취소/되돌리기 5초).
- 거절은 보낸 쪽에 만료와 구분되지 않게 보인다. 표시 시점도 만료 시점으로 맞춘다.
- 취소한 요청은 횟수를 돌려주지 않는다.
- 알림에는 직접 행동 버튼을 두지 않는다. 수락은 판단 근거를 본 화면에서만.
- 동시에 서로 요청한 경우 한쪽 수락으로 양쪽 정리, 시작자는 먼저 보낸 사람.

### 미결정

| 항목 | 결정 Step |
|---|---|
| ~~거절 표시 시점~~ → 최대 하루로 확정 (사용자 결정) | 해결 |
| ~~취소 후 재요청 규칙~~ → 당일 불가, 다음 날부터 (09 §8) | 해결 |
| 노드 드래그 허용 여부(힘 기반 레이아웃에서 혼란 가능) | 디자인 검증 |
