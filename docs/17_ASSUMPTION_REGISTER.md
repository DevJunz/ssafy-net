## 5. 가정 간 의존

```
A-10 (2주 집중) ─── 모든 시간 파라미터(A-26~A-32, A-38)와 판단 시점의 전제
A-11 (유입) ─── A-01 이하 전부의 분모
A-01 (관심사 등록) ─── A-02 ─┬─ A-03 → A-04 → A-05 (사슬)
                            ├─ A-06 (Network)
                            └─ A-07 (그래프)
A-12, A-17 (실명) ─── A-05
A-13, A-14 (알림) ─── A-04, A-09
A-16 (차단 부재) ─── A-04 (불쾌 경험이 수락률을 낮출 수 있음)
```

A-10과 A-11이 틀리면 나머지 가정의 검증 자체가 불가능하다. 공개 첫날 이 둘을 먼저 본다.
