## 1. 게시글의 존재 이유

> **게시글은 "이 관심사에서 누가, 무엇을 이야기하고 싶어 하는지"를 드러내 사람 발견의 계기를 만드는 장치다.** 커뮤니티가 아니다.

| 게시글이 하는 일 | 게시글이 하지 않는 일 |
|---|---|
| 관심사 상세에서 "활동 중인 사람"을 보여준다 | 정보 공유, 질문-답변 |
| 연결 요청 메시지의 소재가 된다 | 토론, 댓글 |
| 프로필에서 "이 사람이 무엇을 이야기하고 싶어 하는지"를 보여준다 | 인기 측정(좋아요, 조회수) |
| 관심사가 태그로 끝나지 않게 한다 | 피드 소비 |

이 정의를 지키기 위해 기능을 의도적으로 빈약하게 유지한다. 글의 유일한 출구는 **"작성자 프로필 보기 → 연결 요청"**이다.

---

## 2. 작성

| 규칙 | 내용 | 이유 |
|---|---|---|
| 누가 | **해당 관심사를 선택한 사용자만** | 관심사 없이 글을 쓰면 "관심사 = 활동"의 연결이 끊긴다. 글을 쓰려면 관심사를 추가하도록 유도 |
| 형식 | 텍스트 한 덩어리, `[P-17]` 300자 이하. 제목 없음, 이미지 없음, 링크는 텍스트로만 | 짧아야 "이야기하고 싶은 것"이 된다. 길면 정보글이 된다 |
| 관심사 지정 | 글 하나에 관심사 **하나** | 여러 관심사에 걸치면 "이 관심사에서 활동 중"의 의미가 희석된다 |
| 횟수 | 관심사당 하루 1개, 전체 하루 3개 | 게시판화 방지 |
| 작성자 표시 | 표시명(닉네임 또는 실명). 연결된 사람에게는 실명도 | 12_PRIVACY와 동일 |
| 유도 문구 | 입력 화면: "이 관심사로 어떤 이야기를 나누고 싶은지 남겨보세요. 댓글은 없고, 관심 있는 사람이 프로필로 찾아옵니다." | 용도를 매번 상기 |

## 3. 수정, 삭제

| 규칙 | 내용 |
|---|---|
| 수정 | **없음.** 삭제 후 재작성 |
| 삭제 | 작성자 언제든. 삭제 즉시 모든 곳에서 사라짐 |
| 운영자 삭제 | 신고 처리 시. 작성자에게 사유 알림 |
| 관심사를 제거하면 | 그 관심사에 쓴 내 글은 **함께 숨겨진다.** 관심사를 다시 추가하면 복구 |
| 탈퇴하면 | 모든 글 삭제 |

## 4. 노출

| 어디에 | 무엇을 | 정렬 |
|---|---|---|
| 관심사 상세 | 그 관심사의 글 | 최신순. 5개씩 더 보기 |
| Person Profile | 그 사람의 글 | 최신순. 3개 |
| 요청 상세 (받은 요청) | 보낸 사람의 최근 글 | 판단 정보의 일부 |
| 연결 성립 화면 | 상대의 최근 글 | 첫 메시지 소재 |
| 묶음 알림 (S3) | 내 관심사의 새 글 개수 | "#백엔드에 새 글 3개" |
| 전체 피드 | **없음** | |
| 검색 | **없음** | |

- 오래된 글 처리 (OQ-7): MVP에서는 **만료 없음.** 집중 사용 기간이 2주라 만료가 의미 없다. 날짜를 표시해 사용자가 판단하게 한다. MVP 후 30일 이상 된 글을 "오래된 글"로 접는 것을 검토.

## 5. 하지 않는 것과 그 이유

| 기능 | 결정 | 이유 |
|---|---|---|
| 댓글 | **없음** (L1) | 댓글이 생기면 대화가 앱 안에서 시작되고, 사내 메신저로 넘어갈 이유가 사라진다. Non-Goal(자체 메신저)의 우회로가 된다 |
| 좋아요 / 반응 | **없음** (L1) | 인기 지표는 관심사보다 인기를 좇게 만든다. "좋아요 많은 사람"이 아니라 "관심사가 겹치는 사람"을 찾아야 한다 |
| 조회수 | 없음 | 같은 이유 |
| 글에서 바로 연결 요청 | **있음.** 글 옆에 "이 사람과 연결" 진입점 | 글의 유일한 출구. 프로필을 거치되 한 번의 클릭으로 |
| 글 공유 | 없음 | 조직 밖으로 나갈 이유가 없음 |
| 멘션, 해시태그 | 없음 | 관심사가 이미 태그다 |

"댓글이 없으면 답할 방법이 없다"는 반론이 예상된다. 답은 **연결 요청의 메시지**다. "NestJS 얘기 하고 싶다고 쓰신 글 보고 연락드려요"가 이 서비스가 원하는 답글이다.

## 6. 신고와 금지 콘텐츠

| 항목 | 내용 |
|---|---|
| 신고 (S5) | 모든 글에 신고. 사유: 광고/홍보, 비방·혐오, 개인정보 노출, 관심사와 무관, 기타 |
| 처리 | 운영자가 확인. 삭제 또는 유지. 신고자에게 결과 통보 없음. 작성자에게는 삭제 시 사유 |
| 금지 콘텐츠 | 상업 광고, 외부 서비스 홍보, 특정인 비방, 정치·종교 선동, 개인정보(전화번호, 주소), 채용·인력 모집(업무 매칭은 Non-Goal), 반복 동일 글 |
| 사전 필터 | MVP에서는 없음. 신고 기반 사후 처리만 |
| 반복 위반 | 삭제 2회 이상이면 글 작성 정지. 운영자 판단 |

## 7. Community Scope Creep 감시

게시글이 커뮤니티로 변질되는지를 다음 신호로 본다.

| 신호 | 의미 | 대응 |
|---|---|---|
| 글에서 프로필로 이동하는 비율이 낮음 (< 20%) | 글이 "읽을거리"로 소비됨 | 글 옆 연결 진입점 강화, 또는 S1을 Later로 |
| 글 길이가 상한에 몰림 | 정보글화 | 상한을 150자로 낮춤 |
| 같은 사람이 매일 글을 씀 | 게시판 사용자 | 횟수 제한 강화 |
| "댓글 없나요" 문의 | 커뮤니티 기대 | 안내 문구 강화. 댓글은 추가하지 않음 |
| 글에서 시작된 연결 요청이 많음 | **성공 신호** | S1 유지, H8 검증 |

## 결정 / 미결정

### 결정됨

- 관심사 보유자만, 300자, 관심사 하나, 관심사당 하루 1개.
- 수정 없음, 삭제 있음. 관심사 제거 시 글 숨김.
- 댓글, 좋아요, 조회수, 피드, 검색 없음. 글의 출구는 연결 요청뿐.
- MVP에서 만료 없음.
- 신고 기반 사후 처리. 금지 콘텐츠에 채용·인력 모집 포함.
