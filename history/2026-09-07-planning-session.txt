❯ # Phase 0 — Direction Validation MVP                                          
                                                                                
  본격적인 PRD와 시스템 설계를 시작하기 전에 반드시 아주 작은 MVP를 먼저        
  만든다.                                                                       
                                                                                
  이 MVP의 목적은 기능 완성이 아니다.                                           
                                                                                
  **사용자가 머릿속으로 생각하고 있는 서비스와 실제 구현된 인터랙션이 같은      
  방향인지 빠르게 확인하는 것**이 목적이다.                                     
                                                                                
  따라서 이 단계에서는 Backend, Database, Authentication, 실제 Recommendation   
  System 등을 구현하지 않는다.                                                  
                                                                                
  가능한 한 Mock Data와 Frontend만 사용한다.                                    
                                                                                
  ---                                                                           
                                                                                
  ## Phase 0의 목표                                                             
                                                                                
  다음 질문에 답할 수 있는 프로토타입을 만든다.                                 
                                                                                
  > 관심사와 사람이 연결된 그래프가 실제로 이해하기 쉬운가?                     
                                                                                
  > 사람을 클릭했을 때 관심사가 Focus되는 UX가 자연스러운가?                    
                                                                                
  > Interest를 클릭했을 때 관련 사람을 발견하기 쉬운가?                         
                                                                                
  > 공통 관심사가 많은 사람을 Person-Person Edge로 연결하는 방식이 이해하기     
  쉬운가?                                                                       
                                                                                
  > 여러 사람이 5개 이상의 관심사를 공유할 때 하나의 Network로 추천하는 개념이  
  직관적인가?                                                                   
                                                                                
  > 사용자가 이 화면을 보고 "이 사람과 연결해보고 싶다"라는 행동으로 이어질     
  가능성이 있는가?                                                              
                                                                                
  ---                                                                           
                                                                                
  # MVP 데이터                                                                  
                                                                                
  실제 사용자 데이터 대신 Mock Data를 사용한다.                                 
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  Person                                                                        
  20~30명                                                                       
                                                                                
  Interest                                                                      
  10~15개                                                                       
  ```                                                                           
                                                                                
  대표 Interest:                                                                
                                                                                
  ```text                                                                       
  축구                                                                          
  백엔드                                                                        
  프론트엔드                                                                    
  AI                                                                            
  OSS                                                                           
  독서                                                                          
  러닝                                                                          
  클라이밍                                                                      
  영화                                                                          
  게임                                                                          
  여행                                                                          
  음악                                                                          
  데이터                                                                        
  DevOps                                                                        
  알고리즘                                                                      
  ```                                                                           
                                                                                
  각 Person은:                                                                  
                                                                                
  ```text                                                                       
  3~8개                                                                         
  ```                                                                           
                                                                                
  Interest를 랜덤 또는 의도적으로 가진다.                                       
                                                                                
  여러 관심사를 공유하는 사용자가 충분히 발생하도록 Mock Data를 설계한다.

  # MVP에서 반드시 구현할 기능                                                  
                                                                                
  ## 1. 기본 Interest Graph                                                     
                                                                                
  다음 관계를 표현한다.                                                         
                                                                                
  ```text                                                                       
  Person ─ INTERESTED_IN ─ Interest                                             
  ```                                                                           
                                                                                
  Interest node는 크게 표시한다.                                                
                                                                                
  Person node는 상대적으로 작게 표시한다.                                       
                                                                                
  한 Person은 여러 Interest에 연결될 수 있어야 한다.                            
                                                                                
  ---                                                                           
                                                                                
  ## 2. Person Focus                                                            
                                                                                
  Person을 클릭하면:                                                            
                                                                                
  ```text                                                                       
  Person                                                                        
   ↓                                                                            
  연결된 Interests                                                              
  ```                                                                           
                                                                                
  만 강조한다.                                                                  
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
          축구                                                                  
            \                                                                   
             \                                                                  
            [민수]                                                              
           /  |  \                                                              
       백엔드 OSS 독서                                                          
  ```                                                                           
                                                                                
  나머지 node/edge는 흐리게 처리한다.                                           
                                                                                
  ---                                                                           
                                                                                
  ## 3. Interest Focus                                                          
                                                                                
  Interest를 클릭하면:                                                          
                                                                                
  ```text                                                                       
  Interest                                                                      
   ↓                                                                            
  해당 Interest를 가진 People                                                   
  ```                                                                           
                                                                                
  을 강조한다.                                                                  
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
                백엔드                                                          
             /    |    \                                                        
           민수   지수   철수                                                   
  ```                                                                           
                                                                                
  ---                                                                           
                                                                                
  ## 4. Person Detail Panel                                                     
                                                                                
  Person을 선택하면 Side Panel에 표시한다.                                      
                                                                                
  ```text                                                                       
  민수                                                                          
                                                                                
  관심사                                                                        
                                                                                
  #백엔드                                                                       
  #축구                                                                         
  #OSS                                                                          
  #독서                                                                         
                                                                                
  나와 공통 관심사                                                              
                                                                                
  #백엔드                                                                       
  #축구                                                                         
  #OSS                                                                          
                                                                                
  공통 관심사 3개                                                               
                                                                                
  [연결 요청]                                                                   
  ```                                                                           
                                                                                
  실제 Connection Backend는 구현하지 않는다.                                    
                                                                                
  버튼 클릭 시:                                                                 
                                                                                
  ```text                                                                       
  연결 요청을 보냈습니다.                                                       
  ```                                                                           
                                                                                
  정도의 Mock Interaction이면 충분하다.                                         
                                                                                
  ---                                                                           
                                                                                
  ## 5. Similar People Mode                                                     
                                                                                
  버튼:                                                                         
                                                                                
  ```text                                                                       
  [나와 비슷한 사람 보기]                                                       
  ```                                                                           
                                                                                
  를 제공한다.                                                                  
                                                                                
  클릭하면:                                                                     
                                                                                
  ```text                                                                       
  공통 Interest >= 3                                                            
  ```                                                                           
                                                                                
  인 Person들을 찾는다.                                                         
                                                                                
  이때 현재 사용자와 해당 Person 사이에 임시 Person-Person Edge를 표시한다.     
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
                 민수                                                           
                                                                                
  축구 · 백엔드 · OSS                                                           
                                                                                
                  │                                                             
                  │                                                             
                                                                                
                [나]                                                            
                                                                                
                  │                                                             
                                                                                
  백엔드 · 독서 · AI                                                            
                                                                                
                  │                                                             
                                                                                
                 지수                                                           
  ```                                                                           
                                                                                
  Edge에는 기본적으로:                                                          
                                                                                
  ```text                                                                       
  공통 관심사 개수                                                              
  ```                                                                           
                                                                                
  만 표시한다.                                                                  
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  나 ── 4 ── 민수                                                               
  ```                                                                           
                                                                                
  Hover 또는 Click 시:                                                          
                                                                                
  ```text                                                                       
  축구                                                                          
  백엔드                                                                        
  OSS                                                                           
  독서                                                                          
  ```                                                                           
                                                                                
  를 보여준다.                                                                  
                                                                                
  ---                                                                           
                                                                                
  # 6. Network Recommendation Prototype                                         
                                                                                
  이 단계에서 실제 추천 알고리즘을 완성할 필요는 없다.                          
                                                                                
  Mock Data를 이용해 미리 조건을 만족하는 Network를 2~3개 만든다.               
                                                                                
  조건 예:                                                                      
                                                                                
  ```text                                                                       
  Member                                                                        
  3~5명                                                                         
                                                                                
  전체 공통 관심사                                                              
  >= 5                                                                          
  ```                                                                           
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  추천 네트워크                                                                 
                                                                                
  민수                                                                          
  지수                                                                          
  철수                                                                          
  나                                                                            
                                                                                
  공통 관심사                                                                   
                                                                                
  #축구                                                                         
  #백엔드                                                                       
  #OSS                                                                          
  #독서                                                                         
  #러닝                                                                         
  ```                                                                           
                                                                                
  이를 그래프로 표현한다.                                                       
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
                민수                                                            
               /   \                                                            
              /     \                                                           
            나 ──── 지수                                                        
              \     /                                                           
               \   /                                                            
                철수                                                            
  ```                                                                           
                                                                                
  그리고:                                                                       
                                                                                
  ```text                                                                       
  [이 네트워크 보기]                                                            
  ```                                                                           
                                                                                
  를 눌렀을 때 해당 사람들만 Focus한다.                                         
                                                                                
  아직 NetworkSuggestion DB나 알고리즘은 구현하지 않는다.                       
                                                                                
  ---                                                                           
                                                                                
  # 7. Interest Posts Prototype                                                 
                                                                                
  Interest를 클릭하면 Side Panel에 간단한 Mock Post를 보여준다.                 
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  백엔드                                                                        
                                                                                
  관심 있는 사람                                                                
  32명                                                                          
                                                                                
  최근 글                                                                       
                                                                                
  민수                                                                          
  NestJS 사용하시는 분 있나요?                                                  
                                                                                
  지수                                                                          
  Redis 운영 경험 이야기 나눠보고 싶습니다.                                     
                                                                                
  [글 작성]                                                                     
  ```                                                                           
                                                                                
  실제 게시글 Backend는 구현하지 않는다.                                        
                                                                                
  Mock Data만 사용한다.

  # 구현 방식                                                                   
                                                                                
  Frontend만 사용한다.                                                          
                                                                                
  추천:                                                                         
                                                                                
  ```text                                                                       
  React                                                                         
  TypeScript                                                                    
  react-force-graph-2d                                                          
  ```                                                                           
                                                                                
  데이터는 다음과 같은 로컬 Mock Data로 관리한다.                               
                                                                                
  ```typescript                                                                 
  const users = []                                                              
                                                                                
  const interests = []                                                          
                                                                                
  const userInterests = []                                                      
                                                                                
  const posts = []                                                              
                                                                                
  const networkSuggestions = []                                                 
  ```                                                                           
                                                                                
  Backend를 만들지 않는다.                                                      
                                                                                
  PostgreSQL을 만들지 않는다.                                                   
                                                                                
  Authentication을 만들지 않는다.                                               
                                                                                
  NestJS를 만들지 않는다.                                                       
                                                                                
  이 단계에서 중요한 것은 Architecture가 아니라 **Interaction Validation**이다.

  # Phase 0 완료 후 반드시 멈춘다                                               
                                                                                
  Phase 0 MVP를 만든 직후 PRD나 Backend 구현으로 넘어가지 않는다.               
                                                                                
  먼저 사용자에게 결과를 보여주고 다음을 확인한다.                              
                                                                                
  ### 질문 1                                                                    
                                                                                
  그래프의 전체적인 형태가 생각한 서비스와 비슷한가?                            
                                                                                
  ### 질문 2                                                                    
                                                                                
  Person과 Interest 관계가 직관적으로 이해되는가?                               
                                                                                
  ### 질문 3                                                                    
                                                                                
  Person을 클릭해 관심사가 Focus되는 방식이 원하는 형태인가?                    
                                                                                
  ### 질문 4                                                                    
                                                                                
  Interest를 클릭해 사람을 탐색하는 방식이 원하는 형태인가?                     
                                                                                
  ### 질문 5                                                                    
                                                                                
  공통 관심사가 많은 사람을 직접 Edge로 연결하는 표현이 자연스러운가?           
                                                                                
  ### 질문 6                                                                    
                                                                                
  5개 이상의 관심사를 공유하는 사람들을 하나의 Network로 추천하는 방식이 원하는 
  개념과 일치하는가?                                                            
                                                                                
  ### 질문 7                                                                    
                                                                                
  Interest 게시글이 그래프와 함께 존재하는 것이 자연스러운가?                   
                                                                                
  ### 질문 8                                                                    
                                                                                
  연결 요청까지만 앱에서 처리하고 실제 대화는 사내 메신저에서 진행하는 흐름이   
  적절한가?                                                                     
                                                                                
  ### 질문 9                                                                    
                                                                                
  추가하거나 제거하고 싶은 핵심 Interaction이 있는가?

  # 이 단계의 가장 중요한 원칙                                                  
                                                                                
  **코드를 많이 작성하는 것이 목표가 아니다.**                                  
                                                                                
  최소한의 구현으로                                                             
                                                                                
  > "내가 만들고 싶은 서비스가 실제로 이런 모습인가?"                           
                                                                                
  를 사용자가 판단할 수 있게 하는 것이 목표다.                                  
                                                                                
  Phase 0에서는 기술적으로 완벽한 코드보다 변경하기 쉬운 코드를 우선한다.       
                                                                                
  MVP가 폐기될 가능성을 항상 전제로 한다.

  2. 관심사 그래프를 탐색하며                                                   
  3. 비슷한 관심사를 가진 새로운 사람 또는 작은 그룹을 발견하고                 
  4. 서로 연결 의사가 있는지 확인한 뒤                                          
  5. 실제 대화는 기존 사내 메신저에서 진행                                      
                                                                                
  하도록 돕는 것이 목적이다.                                                    
                                                                                
  서비스는 자체 메신저가 아니다.                                                
                                                                                
  핵심 역할은:                                                                  
                                                                                
  ```text                                                                       
  Discover                                                                      
  → Understand                                                                  
  → Connect                                                                     
  → External Conversation                                                       
  ```                                                                           
                                                                                
  이다.                                                                         
                                                                                
  ---                                                                           
                                                                                
  # 2. 핵심 Product Model                                                       
                                                                                
  기본적인 관계는:                                                              
                                                                                
  ```text                                                                       
  Person ↔ Interest                                                             
  ```                                                                           
                                                                                
  이다.                                                                         
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
                  축구                                                          
               /   |   \                                                        
             A     B     C                                                      
             |           |                                                      
          백엔드         독서                                                   
  ```                                                                           
                                                                                
  한 사람은 여러 관심사에 동시에 속할 수 있다.                                  
                                                                                
  사람과 사람 사이의 관계는 기본적으로 존재하는 관계가 아니라,                  
                                                                                
  **공통 관심사를 기반으로 발견되는 관계**                                      
                                                                                
  로 본다.                                                                      
                                                                                
  ---                                                                           
                                                                                
  # 3. Interest 정책의 기본 방향                                                
                                                                                
  Interest는 서비스 운영자가 사전에 제공한다.                                   
                                                                                
  초기 규모:                                                                    
                                                                                
  ```text                                                                       
  약 100개                                                                      
  ```                                                                           
                                                                                
  정도를 가정한다.                                                              
                                                                                
  사용자가 자유롭게 새로운 Interest를 만드는 방식은 기본적으로 사용하지 않는다. 
                                                                                
  Interest는 상위 Category 아래에 속할 수 있다.                                 
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  개발                                                                          
  - 백엔드                                                                      
  - 프론트엔드                                                                  
  - AI                                                                          
  - 데이터                                                                      
  - DevOps                                                                      
  - OSS                                                                         
                                                                                
  스포츠                                                                        
  - 축구                                                                        
  - 농구                                                                        
  - 야구                                                                        
  - 러닝                                                                        
  - 클라이밍                                                                    
                                                                                
  문화                                                                          
  - 독서                                                                        
  - 영화                                                                        
  - 음악                                                                        
  - 여행                                                                        
  ```                                                                           
                                                                                
  사용자가 원하는 관심사가 없다면:                                              
                                                                                
  ```text                                                                       
  관심사 제안                                                                   
  ```                                                                           
                                                                                
  기능을 제공하는 방향을 검토한다.                                              
                                                                                
  사용자가 선택 가능한 Interest 개수에는 적절한 최소/최대 제한이 필요하다.      
                                                                                
  이 숫자는 아직 고정된 요구사항이 아니라 기획 과정에서 결정해야 한다.          
                                                                                
  ---                                                                           
                                                                                
  # 4. 핵심 그래프 UX                                                           
                                                                                
  메인 화면에서는 Person과 Interest의 관계를 그래프로 탐색한다.                 
                                                                                
  ## Person 선택                                                                
                                                                                
  Person을 선택하면 해당 Person의 관심사들을 Focus한다.                         
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
               축구                                                             
                 \                                                              
                  \                                                             
                 민수                                                           
                / | \                                                           
            백엔드 OSS 독서                                                     
  ```                                                                           
                                                                                
  관련 없는 영역은 시각적으로 약하게 표현한다.                                  
                                                                                
  사용자는 이 화면에서:                                                         
                                                                                
  * 이 사람이 어떤 관심사를 가지고 있는지                                       
  * 나와 어떤 관심사가 겹치는지                                                 
  * 왜 이 사람이 나와 관련 있는지                                               
                                                                                
  를 빠르게 이해해야 한다.                                                      
                                                                                
  ---                                                                           
                                                                                
  ## Interest 선택                                                              
                                                                                
  Interest를 선택하면 해당 관심사를 가진 사람들이 Focus된다.                    
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
                백엔드                                                          
                                                                                
            /     |     \                                                       
          민수   지수    철수                                                   
  ```                                                                           
                                                                                
  이 기능의 목적은:                                                             
                                                                                
  > 특정 관심사를 중심으로 새로운 사람을 발견하는 것                            
                                                                                
  이다.                                                                         
                                                                                
  ---                                                                           
                                                                                
  # 5. Interest별 콘텐츠                                                        
                                                                                
  각 Interest에는 해당 관심사를 기반으로 한 게시글을 작성할 수 있다.            
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  백엔드                                                                        
                                                                                
  민수                                                                          
  "NestJS 사용하시는 분들과 이야기해보고 싶습니다."                             
                                                                                
  지수                                                                          
  "Redis 운영 경험 있으신 분?"                                                  
  ```                                                                           
                                                                                
  게시글의 목적은 일반적인 커뮤니티 서비스를 만드는 것이 아니다.                
                                                                                
  다음을 위한 Context 생성이 핵심이다.                                          
                                                                                
  * 해당 관심사에서 누가 활동하는지 알기                                        
  * 사람을 발견할 계기 만들기                                                   
  * 네트워킹을 시작할 주제 제공                                                 
  * 관심사가 단순 프로필 태그로 끝나지 않게 하기                                
                                                                                
                                                                                
  ──── (975 lines hidden) ───────────────────────────────────────────────────── 
   Risk에 대해:                                                                 
                                                                                
  ```text                                                                       
  Likelihood                                                                    
  Impact                                                                        
  Possible Mitigation                                                           
  MVP에서 대응 필요 여부                                                        
  ```                                                                           
                                                                                
  를 작성한다.                                                                  
                                                                                
  ---                                                                           
                                                                                
  # 34. Product Decision Log                                                    
                                                                                
  기획 과정에서 중요한 의사결정을 기록한다.                                     
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  Decision:                                                                     
  앱 내부 DM을 만들지 않는다.                                                   
                                                                                
  Reason:                                                                       
  이미 사내 메신저가 존재하며,                                                  
  서비스의 핵심 가치는 대화가 아니라 Discovery와 Consent에 있기 때문이다.       
  ```                                                                           
                                                                                
  최소 현재까지 결정된 핵심 Product Decision을 정리한다.                        
                                                                                
  ---                                                                           
                                                                                
  # 35. Assumption Register                                                     
                                                                                
  아직 검증되지 않은 가정을 별도로 관리한다.                                    
                                                                                
  예:                                                                           
                                                                                
  ```text                                                                       
  A-01                                                                          
                                                                                
  사용자는 최소 5개의 Interest를 선택할 것이다.                                 
                                                                                
  Status:                                                                       
  Unvalidated                                                                   
  ```                                                                           
                                                                                
  ```text                                                                       
  A-02                                                                          
                                                                                
  공통 Interest 5개는 의미 있는 Network를 만들기에 충분하다.                    
                                                                                
  Status:                                                                       
  Unvalidated                                                                   
  ```                                                                           
                                                                                
  가정과 확정 요구사항을 절대 섞지 않는다.                                      
                                                                                
  ---                                                                           
                                                                                
  # 36. Open Questions                                                          
                                                                                
  기획을 완료하면서 아직 결정되지 않은 문제를 모은다.                           
                                                                                
  각 질문을:                                                                    
                                                                                
  ```text                                                                       
  Blocking                                                                      
  Important                                                                     
  Later                                                                         
  ```                                                                           
                                                                                
  로 구분한다.                                                                  
                                                                                
  Blocking만 개발 설계 전에 반드시 결정해야 한다.

  # 39. 중요한 행동 원칙                                                        
                                                                                
  내 아이디어에 무조건 동의하지 않는다.                                         
                                                                                
  기획자로서 다음 질문을 계속 던진다.                                           
                                                                                
  > 이것이 실제 사용자 문제를 해결하는가?                                       
                                                                                
  > 그래프여야 할 이유가 있는가?                                                
                                                                                
  > 리스트나 검색으로 더 쉽게 해결할 수 있는 기능은 아닌가?                     
                                                                                
  > 이 기능이 새로운 사람 발견 또는 연결 행동에 실제로 기여하는가?              
                                                                                
  > 게시글 기능이 핵심 경험을 강화하는가?                                       
                                                                                
  > 사용자가 왜 다시 방문해야 하는가?                                           
                                                                                
  > 추천을 받은 사람이 왜 연결 요청을 보내야 하는가?                            
                                                                                
  > 요청을 수락한 후 실제 사내 메신저 연락으로 이어질 이유가 충분한가?          
                                                                                
  > 1:1 연결과 Network 추천은 서로 다른 가치를 제공하는가?                      
                                                                                
  불필요한 기능이라 판단하면 삭제 또는 Later로 이동할 것을 제안한다.

● 다섯 가지 모두 제품 정의에 영향을 주는 사항이라 PM 판단을 먼저 드리고, PRD와
  MVP Scope에 반영하겠습니다.

  1. 알림 — 동의합니다. Must Have로 올립니다.

  웹 서비스의 알림은 "사용자가 이미 있는 곳"에 도착해야 합니다. 이 서비스는
  대화의 목적지가 사내 메신저이므로, 알림도 사내 메신저에 오는 것이 가장
  자연스럽습니다. 우선순위를 이렇게 제안합니다.

  - 1순위 사내 메신저 알림. 요청이 왔다는 알림과 실제 대화가 같은 곳에서
    일어납니다. 환경 확인이 필요합니다(OQ-4).
  - 2순위 이메일. 즉시 알림은 요청/수락/성립만, 추천과 새 글은 주 1회 묶음.
  - 보조 브라우저 알림. 사용자가 허용한 경우에만. 기본으로 요구하지 않습니다.
  - 항상 앱 내 알림함.

  알림 원칙은 세 가지입니다. 알림 자체에 판단 근거(누구, 공통 관심사 몇 개,
  메시지 일부)가 들어가야 하고, 한 번의 이동으로 수락/거절 화면에 도착해야 하며,
  사용자가 빈도를 줄일 수 있어야 합니다.

  2. 실명 연결 — 반영합니다. 메신저 ID 대신 실명 + 소속을 공개합니다. 동명이인
  대비로 소속은 함께 공개되어야 메신저에서 찾을 수 있습니다.

  3. 로그인 — 간편 로그인은 제품 요구사항으로 넣되, 두 가지를 분리해야 합니다.

  - 로그인 수단(Google, GitHub 등)은 편의성 문제입니다.
  - 조직 구성원 검증은 신뢰의 근거이므로 별도 요구사항입니다. 서비스의 전제가
    "같은 조직 사람"이기 때문입니다.

  Google 계정이 조직 이메일과 같다면 로그인과 검증이 한 번에 됩니다. GitHub는
  개인 계정이라 조직 소속을 증명하지 못하므로 초대 링크나 조직 이메일 인증을 한
  번 거쳐야 합니다. 어느 쪽이든 소셜 계정의 이름은 실명이 아닐 수 있어,
  온보딩에서 실명 확인 단계가 필요합니다. 기술 선택은 하지 않고 이 요구사항만
  PRD에 넣습니다.

  4. 닉네임 vs 실명 — 세 안을 비교한 뒤 연결 전 닉네임, 수락 시 상호 실명 공개를
  추천합니다.

  안: 처음부터 실명
  장점: 신뢰 높음, 스팸 적음
  단점: 내 관심사가 실명으로 전사 공개됩니다. 취미나 사적 관심사 등록을 위축시켜

  H1을 해칩니다. 팀과 직급을 보고 판단하는 편향이 생깁니다
  ────────────────────────────────────────
  안: 닉네임 → 수락 시 실명
  장점: 관심사만으로 발견됩니다. 요청 보내는 부담이 낮습니다. "수락 = 실명
  공개"가 명확한 동의 지점이 되어 Consent Before Contact와 일치합니다
  단점: 받는 쪽이 누군지 모른 채 수락해야 합니다. 익명 커뮤니티로 변질될 위험이
  있습니다
  ────────────────────────────────────────
  안: 사용자 선택
  장점: 유연함
  단점: 실명 사용자는 자신을 드러내고 상대는 가명인 비대칭이 생겨 결국 대부분
  닉네임을 고릅니다. 복잡성만 늘어납니다

  두 번째 안을 고르되 단점을 이렇게 막습니다. 닉네임과 함께 소속의 대분류(예:
  캠퍼스, 본부)와 관심사는 공개하고, 실명 공개는 수락 순간 양쪽 동시에 이루어져
  위험이 대칭입니다. 게시글은 댓글이 없고 신고가 있어 익명 게시판화를
  제한합니다. 다만 이 선택은 수락률(H4)에 직접 영향을 주므로 핵심 가정으로
  등록하고, MVP 데이터로 재검토합니다.

  5. 구체적 연결 Action — 가장 중요한 보완입니다. Step 1에서 가장 약한 고리로
  꼽은 H5(수락 후 실제 대화)를 직접 다룹니다. Later였던 항목을 Must로 올립니다.

  - 1:1 성립 시: 요청을 보낸 사람이 시작합니다. 이미 의사와 메시지를 냈으므로
    "○○님, 사내 메신저에서 △△님을 찾아 첫 메시지를 보내주세요"로 안내합니다.
  - Network 성립 시: 시작자 한 명을 지정합니다. 규칙은 "가장 먼저 참여를 누른
    사람"이 단순하고 설명 가능합니다. "주영님이 민수님, 지수님을 초대해 대화를
    시작해주세요"와 함께 초대할 실명 목록과 공통 관심사 기반 첫 메시지 소재를
    제공합니다.
  - 시작자가 일정 기간 행동하지 않으면 나머지에게 "누구든 시작해도 됩니다"를
    안내합니다. 기간은 Product Parameter입니다.

  미뤄온 두 설계 질문의 결정

  1. 기본 그래프 범위(OQ-1). 전체 조직을 그리지 않고 항상 앵커가 있습니다. 기본

     순 30명(관심사당 최소 2명 보정), 그 사람들이 많이 가진 인접 관심사 8개까지

     앵커가 되지 않습니다. 사람 중심 탐색은 아는 사람 찾기와 가까워집니다.
  2. Network 모드 선 표현. 네트워크 하나를 허브 노드 하나로 만들고 멤버는 허브에

     사라지고, "이 사람들이 하나의 그룹 후보"라는 의미가 정확해집니다. 1:1
     Similarity Edge는 그대로 사람 간 선이라 두 개념이 시각적으로 구분됩니다.
